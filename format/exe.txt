Output format for the assembler and linker
Header total 40 bytes
4 Identification bytes which must be:
    0x04 0x4F 0x52 0x49
1 Type byte
    Possible values
        0 = INVALID
        1 = OBJECT
        2 = EXECUTABLE
        3 = KERNEL FILE
1 Endianness byte (0 = little 1 = big)
1 Arch byte
    Possible values
        0 = INVALID
        1 = X86
        2 = x64
1 Reserved byte
8 Entry bytes
8 Section offset bytes
    Always 40 AKA after this header
4 Flag bytes
    Possible values
        0 = NO FLAGS
        TODO: add flags
1 Section size byte
    Always 48
2 Section number bytes
2 String section bytes
7 Padding bytes
Section header total 48 bytes
1 Type byte
    Possible values
        0 = INVALID
        1 = STRING SECTION
        2 = SYMBOL SECTION
1 Reserved byte
2 Allignment bytes
8 Virtual addr bytes
8 Memory size bytes
8 File size bytes
8 String table index bytes
8 Offset in file size bytes
1 Flags byte
    Possible values
        0 = NONE
        1 = LOAD
        2 = EXECUTE
        4 = WRITE
3 Padding bytes
Symbol Entry 18+N bytes total
8 String table name index bytes
8 Size bytes
2 Info bytes
N Value bytes
String symbol 16+N bytes total
8 String index bytes (current index)
8 Size bytes
N Value bytes (Null terminated)
